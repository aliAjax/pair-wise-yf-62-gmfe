# 海上搜救联合指挥

源提示词摘要：按海域划设搜索区，协调船艇、直升机、无人机和岸上观察点，记录任务变更、通信与天气影响；离线单位恢复后合并状态，过期位置必须明确提示，并提供低带宽模式。

## 按实际航迹记账的责任账

任务单、搜索区、执行单位不再按计划记覆盖率，而是以船艇/无人机**实际回传航迹**重算，两边对账同源：

- **交叠水域先定主责**：搜索区交叠自动生成共享带，主责区先划定；带内航迹只归主责区，另一区计协同。未定主责的交叠点暂不计账并告警。
- **同时段唯一计入**：以 15 分钟为记账时段，同一单位同一时段只产生一条主责账；槽主责按原始回传点投票（带内点投带主责区，单区点多数决，平局取任务计划区），航迹插值只用于覆盖率补格。飞偏到其他区算协同，飞偏出界计漂移，计划时段无航迹计漏飞。
- **变化即失效重算**：搜索区边界或带主责变化（区 `rev+1`）、任务单位或搜索区变化（任务 `rev+1`）后，原占用失效，覆盖率从不可变航迹整体重算；已不挂当前单位的旧航迹记 `detached`，不进当前主责覆盖率。
- **容量排队**：按单位 `concurrentCapacity` 校验计划时段重叠，超容量任务进入排队（紧急 > 开始时间 > 业务编号），任务关闭或容量调整后自动递补。
- **离线按业务编号合并**：报告按 `reportId` 幂等、按业务编号+单位合并分片；任务关闭后到达的晚到旧报告只补历史（`latePrimaryCells` / `primaryPercentWithLate`），不触动在执行占用与排队。
- **旧数据回填**：persist v1→v2 迁移时无主责范围，按历史任务最早边界回填交叠带主责（`backfilled`），无历史依据的列为待裁定。

纯函数引擎在 `src/lib/ledger/`（`geometry` 栅格/时段、`ledger` 记账、`schedule` 容量排队、`belts` 交叠与回填、`reports` 离线合并），12 个规则用例：`npm test`。

## 技术栈

Next.js 15、TypeScript、App Router、Mantine、Zustand、TanStack Query、React Hook Form、Zod、next-intl、date-fns、MapLibre、Vitest。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62027`

## 可用流程

- 搜索区从规划、执行到关闭，支持任务范围变更。
- 船艇、直升机、无人机可调派、转入失联、恢复在线。
- 任务单支持新建议题、分配单位、关闭任务和事件留痕。
- 交叠带定主责、容量排队、离线分片合并、晚到补历史、变更失效重算均可在界面演示。
- 离线模拟与低带宽模式可切换；本地数据由 Zustand persist（v2，含 v1 迁移）保存。
