# 海上搜救联合指挥

源提示词摘要：按海域划设搜索区，协调船艇、直升机、无人机和岸上观察点，记录任务变更、通信与天气影响；离线单位恢复后合并状态，过期位置必须明确提示，并提供低带宽模式。

## 技术栈

Next.js 15、TypeScript、App Router、Mantine、Zustand、TanStack Query、React Hook Form、Zod、next-intl、date-fns、MapLibre。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62027`

## 可用流程

- 搜索区从规划、执行到关闭，支持任务范围变更。
- 船艇、直升机、无人机可调派、转入失联、恢复在线。
- 任务单支持新建议题、分配单位、关闭任务和事件留痕。
- 离线模拟与低带宽模式可切换；本地数据由 Zustand persist 保存。

## 按实际航迹记账的责任账

搜索区、执行单位、任务单接成一份按实际航迹记账的责任账，收队时两边对账一致：

- **交叠水域先定主责区**：重叠搜索区在「主责区」卡片指定主责方；共享带航迹归主责区，另一区算协同。
- **同一单位同一时段只计入一个搜索区**：派发或变更任务时，该单位在异区的原占用自动失效（状态 `invalid`），并重算覆盖率。
- **覆盖率按实际航迹重算**：在线航迹或离线回传合并后，按航迹点落在哪个搜索区、是否有有效占用、是否主责区来统计覆盖网格；飞偏（区外）与漏飞（无点）都不会虚增覆盖率。
- **超出单位同时段容量时任务排队**：单位有容量上限（船 2、直升机/无人机 1、岸点 3），占满后新任务进容量队列，腾出容量后可一键补入占用。
- **离线回传按业务编号合并**：离线单位回传按任务单业务编号合并入台账；晚到的旧报告只补历史、不计覆盖率。
- **升级回填**：旧持久化数据没有主责范围时，升级按历史任务边界回填主责区、补 `businessNo` 与容量、并为进行中任务补占用。

核心纯逻辑在 `src/lib/ledger.ts`，状态动作在 `src/lib/store.ts`，可通过 `scripts/` 下的测试脚本验证。
